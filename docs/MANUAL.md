# Rapoo 게이밍 마우스 Linux 네이티브 드라이버 및 제어 센터 완벽 가이드

본 문서는 리눅스(Fedora, Ubuntu, Arch 등) 환경에서 **Rapoo 게이밍 마우스(VT3PRO MAX / VT1PRO MAX / VT9PRO / VT9Air)**를 전용 소프트웨어 없이 100% 하드웨어 온보드로 제어하는 C/C++ 네이티브 드라이버의 설치, GUI/CLI 사용법 및 문제 해결을 다룹니다.

## 1. 기기 사양 및 아키텍처

- **지원 기기**: Rapoo VT3PRO MAX / VT1PRO MAX / VT9PRO / VT9PRO 4K / VT9Air / B-Cut 계열
- **USB 식별자**: VID `0x24ae` : PID `0x1244`
- **광학 센서**: PixArt PAW3398 / PAW3395 (최대 26,000 DPI, 650 IPS, 50G 가속)
- **통신 방식**: Linux 커널 `/dev/hidraw` 직결 (Report ID `0xba` 32바이트 IOCTL)
- **핵심 특징**:
  * **Zero Python / Zero Wine**: 100% C99 및 C++ 네이티브로 빌드되어 파이썬 런타임 오버헤드가 없습니다.
  * **Zero Software Injector**: `uinput`, `xdotool` 등의 가상 입력 후킹이 아닌, 마우스 온보드 EEPROM/플래시에 직접 기록하여 OS 리소스 점유율 0.00%를 달성합니다.
  * **초경량 최적화**: CLI 실행 파일 40 KB, 기동 시간 6ms, 메모리 점유율 1.5 MB.

## 2. 설치 및 빌드 방법

### 2.1 원클릭 자동 설치 (권장)
터미널에서 아래 명령을 실행합니다:
```bash
cd rapoo-linux-driver
./install.sh
```
* `make all`로 C 드라이버, CLI, GTK3 GUI를 컴파일합니다.
* 실행 파일(`rapoo-mouse`, `rapoo-mouse-gui`)을 `~/.local/bin/`에 복사합니다.
* 비루트 일반 사용자 HID 권한(`/etc/udev/rules.d/70-rapoo-mouse.rules`)을 등록합니다.
* 부팅 시 자동 적용 `systemd` user 서비스(`rapoo-mouse.service`)를 활성화합니다.

### 2.2 수동 빌드 (Makefile)
```bash
make all      # bin/rapoo-mouse, bin/rapoo-mouse-gui, build/librapoo.a 빌드
make install  # ~/.local/bin 및 ~/.local/include/rapoo에 설치
make clean    # 빌드 산출물 정리
```

### 2.3 삭제 (Uninstall)
```bash
./uninstall.sh
```

## 3. GTK3 GUI 제어 센터 가이드

터미널에서 `rapoo-mouse-gui`를 입력하거나 애플리케이션 메뉴에서 **"라푸 마우스 제어"**를 실행합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [🔋 100% (무선)] [🔄]     라푸 마우스 제어 센터      [마우스에 즉시 적용] │
├────────────────────────────────────────────────────────────────────────┤
│  [ 🎯 DPI 설정 ]   [ ⚡ 센서&폴링 ]   [ 🖱️ 버튼&매크로 ]   [ ℹ️ 정보 ]   │
│                                                                        │
│  🎯 현재 활성 DPI 단계: [ 2000 DPI ] ──●─────────                      │
│  [400] [800] [1200] [1600] [2000] [2400] [3200] [6400]                │
│                                                                        │
│  📊 DPI 단계별 상세 설정 (사용할 단계 수: [ 1단계 ▼ ])                    │
│  (●) 1단계 (Stage 1) : [ 2000 ] DPI                                    │
│  ( ) 2단계 (Stage 2) : [ 1200 ] DPI                                    │
│  ...                                                                   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 상단 헤더바
- **실시간 배터리 뱃지**: 마우스와 무선 통신하여 배터리 잔량(%) 및 유선 충전 중/무선 상태를 실시간 표시합니다.
- **새로고침 버튼 [🔄]**: 마우스 상태를 즉각 다시 조회합니다. (백그라운드에서 30초마다 자동 갱신됩니다)
- **마우스에 즉시 적용 (Apply)**: 현재 GUI에서 변경한 모든 설정(DPI, 폴링레이트, 센서, 버튼 매핑)을 마우스 하드웨어 EEPROM에 즉각 플래싱합니다.

### 3.2 탭별 상세 기능
1. **🎯 DPI 설정**:
   - 상단 슬라이더 및 스핀박스로 50 ~ 26,000 DPI 사이를 50 단위로 정밀 조절할 수 있습니다.
   - 하단 프리셋 버튼(400, 800, 1600, 2000 등)을 클릭하면 즉각 해당 수치로 반영됩니다.
   - 단일 감도를 원하는 경우 '사용할 단계 수'를 `1단계`로 맞추면 상단 DPI 버튼을 실수로 눌러도 속도가 변하지 않습니다.
2. **⚡ 센서 & 폴링레이트**:
   - **폴링레이트**: 125Hz, 250Hz, 500Hz, **1000Hz (표준 권장)**, 2000Hz, 4000Hz, 8000Hz 선택.
   - **LOD (Lift-Off Distance)**: 0.7mm ~ 1.7mm (기본 권장값 1.1mm) 조절로 마우스를 살짝 들었을 때 바닥 인식 센서 컷오프 높이를 튜닝합니다.
   - **디바운스 지연 (Debounce)**: 1ms ~ 10ms (기본 권장값 2ms) 조절로 클릭 반응속도 향상 및 더블클릭 오작동 방지.
   - **모션 싱크 (Motion Sync)**: 센서 신호 트래킹 동기화 토글.
3. **🖱️ 버튼 & 매크로**:
   - 마우스 10개 물리 버튼(좌/우/휠클릭/상단DPI/DPI-/앞으로/뒤로/휠업/휠다운/바닥DIY) 기능 지정.
   - **온보드 매크로 플래셔**:
     - 업로드할 슬롯(0~5), 키 시퀀스(`p + enter`, `ctrl + c` 등), 지연시간(ms)을 입력 후 **[마우스 플래시 메모리에 업로드]** 버튼을 누르면 마우스 내부 플래시에 영구 저장됩니다.
4. **ℹ️ 디바이스 정보**:
   - 하드웨어 VID:PID, 디바이스 노드, PixArt 센서 사양 및 프로필 저장 경로 안내.

## 4. CLI 커맨드라인 제어 가이드

스크립트 자동화나 터미널 작업 시 `rapoo-mouse` 명령어를 사용합니다.

```bash
# 1. 마우스 연결 상태 및 실시간 배터리/DPI 확인
rapoo-mouse status

# 2. DPI 단계 설정 (단일 단계 또는 다중 단계)
rapoo-mouse dpi 2000
rapoo-mouse dpi 800 1200 1600 2000 2400

# 3. 폴링레이트 설정 (Hz)
rapoo-mouse polling 1000

# 4. 센서 설정 (LOD mm, 디바운스 ms)
rapoo-mouse sensor 1.1 2

# 5. 하드웨어 매크로 업로드 (슬롯 0에 P+Enter 저장)
rapoo-mouse macro 0 "p + enter"

# 6. 버튼 리매핑 (Key 5 상단버튼에 매크로 슬롯 0 할당)
rapoo-mouse remap 5 41 0

# 7. 지원 버튼 및 기능 번호 목록 확인
rapoo-mouse list-buttons
rapoo-mouse list-functions

# 8. 저장된 설정 파일(~/.config)을 마우스에 일괄 적용
rapoo-mouse apply
```

## 5. 온보드 하드웨어 매크로 플래셔 원리 및 작성법

### 5.1 온보드 하드웨어 매크로의 원리
- 본 드라이버의 온보드 매크로는 OS 가상 입력 소프트웨어(`xdotool`, `uinput` 등)에 의존하지 않고, **마우스 내부 온보드 플래시 메모리(`0x1000 ~ 0x5000`)**에 바이트코드를 기록합니다.
- 버튼을 누르면 마우스 내부 Realtek MCU가 **자체 하드웨어적으로 USB HID 표준 키보드 패킷을 직접 송출**하므로, 운영체제나 백그라운드 프로세스 없이 단독으로 동작합니다.

### 5.2 지원하는 키 매크로 문법
- **단일 연속 입력**: `p + enter` ➔ P를 누르고 50ms 후 Enter 입력 후 뗌.
- **동시 입력 콤보**: `ctrl + c`, `ctrl + v` ➔ Ctrl을 누른 상태에서 C를 누르고 순차적으로 뗌.
- **게임 커맨드 연계**: `space + c` ➔ 슈퍼점프 / 슬라이딩 점프 연계.
- **사용자 정의 딜레이**: `p + 100ms + enter` ➔ P 입력 후 100ms 대기 후 Enter.

## 6. 부팅 영속화 및 udev 핫플러그 연동

### 6.1 `systemd` User Oneshot Service
- 파일 위치: `~/.config/systemd/user/rapoo-mouse.service`
- 로그인 시 1회 실행되어 마우스에 저장된 프로필을 확인/주입하고 6ms 만에 정상 종료됩니다.
- 상태 확인:
  ```bash
  systemctl --user status rapoo-mouse.service
  ```

### 6.2 `udev` 규칙
- 파일 위치: `/etc/udev/rules.d/70-rapoo-mouse.rules`
- `sudo` 없이도 일반 사용자 권한으로 `/dev/hidraw1` 노드에 읽기/쓰기 접근할 수 있도록 권한을 자동 부여합니다.

## 7. 자주 묻는 질문 (FAQ) 및 문제 해결

### Q1. "마우스 하드웨어 노드를 열 수 없습니다" 에러가 발생합니다.
- 마우스 USB 동글 또는 유선 케이블이 연결되어 있는지 확인하세요.
- udev 권한이 적용되지 않은 경우 터미널에서 다음 명령을 실행합니다:
  ```bash
  sudo cp udev/70-rapoo-mouse.rules /etc/udev/rules.d/
  sudo udevadm control --reload-rules && sudo udevadm trigger
  ```

### Q2. `rapoo-mouse status` 실행 시 "마우스 절전/대기 모드"라고 나옵니다.
- 무선 마우스는 배터리 절약을 위해 몇 분간 조작이 없으면 절전 모드로 진입합니다.
- 마우스를 1~2초간 살짝 흔들거나 클릭한 후 다시 실행하면 배터리 잔량과 상태가 즉시 수신됩니다.

### Q3. DPI를 2000으로 설정했는데 마우스가 너무 느리게 움직입니다.
- 마우스 하드웨어 레지스터는 16비트 리틀엔디언(uint16 LE) 다이렉트 규격을 사용합니다. 본 C 드라이버는 이를 완벽히 준수하므로 아래 명령으로 정상화할 수 있습니다:
  ```bash
  rapoo-mouse dpi 2000
  ```

### Q4. C++ 프로젝트에서 이 드라이버를 직접 인클루드해 쓸 수 있나요?
- 네, `include/rapoo_mouse.hpp`를 include하여 C++ RAII 클래스로 사용할 수 있습니다:
  ```cpp
  #include "rapoo_mouse.hpp"
  rapoo::Mouse mouse;
  if (mouse.open()) {
      mouse.setDpiStages({2000});
      mouse.commit();
  }
  ```
